# 20 plantillas de portada · Pizarra y tinta

Archivos SVG independientes y editables. Cada archivo tiene título, comunidad/localidad y fecha como textos con IDs event-title, event-subtitle y event-date. Sustituye esos textos y ajusta sus saltos de línea al exportar. No representan convocatorias nuevas.

El mock utiliza los motivos del catálogo con los títulos y fechas reales, ajustados mediante CSS. Una plantilla conserva identidad, tono y composición.

Regenerar desde la raíz: node tools/build_cover_templates.cjs

index.json registra IDs, nombres, tonos y huellas SHA-256.
